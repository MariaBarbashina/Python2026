## Как запускать

Я делала работы на Python 3.12, сторонние библиотеки не нужны.

Чтобы запустить программу, нужно перейти в папку работы:

```text
cd lab01
python variant.py
```

В Windows вместо `python` можно писать `py`.

Тесты в работах 7–12 запускаются так же из папки работы, например:

```text
cd lab07
python test_functions.py
```

Если всё правильно, в конце выводится `Все проверки пройдены`.
