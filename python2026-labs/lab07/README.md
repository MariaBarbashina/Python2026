### Тест обнаруживает неправильное решение

Ошибки вносились во временную копию `functions.py`. Исправная версия в репозитории не менялась.

1. Из `sum_digits` убрана строка `number = abs(number)`. Проверки упали:
   ```text
   assert sum_digits(-507) == 12
   AssertionError
   ```
   Для отрицательного числа цикл `while number > 0` сразу завершается, поэтому получается `0` вместо `12`.
2. В `select_numbers` условие `-threshold <= number <= 0` заменено на `-threshold < number <= 0`, то есть граница исключена. Проверки упали:
   ```text
   assert select_numbers([-3, -2, -1, 0, 1], 2) == [-2, -1, 0]
   AssertionError
   ```

После возврата исправной версии `python test_functions.py` снова выводит `Все проверки пройдены`.

## Ответы на вопросы защиты

- **Возврат и вывод.** `return` передаёт значение вызывающему коду: его можно сохранить, сравнить в `assert`, передать в другую функцию. `print()` только показывает текст человеку и ничего не возвращает, а функция без `return` возвращает `None`. Поэтому функции модуля возвращают результат, а выводом занимается `main.py`.
- **Локальная переменная и параметр.** Параметр (`numbers`, `threshold`) — имя в заголовке функции, которое при вызове получает значение аргумента. Локальная переменная (`selected`, `total`) создаётся внутри функции присваиванием. И те и другие существуют только во время вызова и не видны снаружи.
- **`if __name__ == "__main__":`.** При запуске `python main.py` вызывается `main()`. При импорте файла как модуля ввод не запускается.
- **Почему `assert`, а не проверка ввода.** `assert` используется для учебной проверки функций. При оптимизированном запуске (`python -O`) такие проверки отключаются, поэтому проверять ввод пользователя через `assert` нельзя.
- **Дополнительное задание.** Проверки `is_palindrome` (раздел в `test_functions.py`) сформулированы по правилам работы №5 до реализации функции: палиндром с пробелами и разным регистром, одна буква с пробелами, пустой текст и строка из пробелов (`False`), `Python`, `А!`. Затем написана функция, и все проверки прошли.
