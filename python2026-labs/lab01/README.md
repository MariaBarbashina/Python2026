### variant.py (вариант 10, «Пекарня»)

**Собственный пример, рассчитанный вручную до запуска.** Заказ «Праздничный набор к чаю», заказчик Анна Смирнова:

- Булочки с корицей: 6 × 25.50 = **153.00**
- Пироги с вишней: 2 × 180.00 = **360.00**
- Товары без доставки: 153.00 + 360.00 = **513.00**
- Доставка 50.00, итого: 513.00 + 50.00 = **563.00**
- Количество единиц: 6 + 2 = **8**
- Внесено 563.00, сдача: 563.00 − 563.00 = **0.00**

|---|---|---|

### variant_discount.py (дополнительное задание)

Скидка считается от стоимости товаров и не затрагивает доставку: `итог = товары − товары × скидка / 100 + доставка`.

| Ввод | Ожидаемый результат | Фактический результат |
|---|---|---|
| Тот же заказ, скидка `10`, внесено `100.00` | скидка `7.75`, итог `79.75`, сдача `20.25` | `7.75`, `79.75`, `20.25` |
| Скидка `0`, внесено `87.50` | скидка `0.00`, итог `87.50`, сдача `0.00` | `0.00`, `87.50`, `0.00` |
| Скидка `100`, внесено `10.00` | скидка `77.50`, итог `10.00` (только доставка), сдача `0.00` | `77.50`, `10.00`, `0.00` |

## Ответы на вопросы защиты

- **Строка и число.** `"2"` — текст (`str`), `2` — число (`int`). Для строк `+` выполняет соединение (`"2" + "3" == "23"`), для чисел — сложение. `input()` всегда возвращает строку, поэтому для расчётов её нужно преобразовать через `int()` или `float()`.
- **Порядок вычислений.** Сначала выполняются `*` и `/`, затем `+` и `-`. Скобки меняют порядок: `(4 + 7 + 10) / 3 = 7.0`, а `4 + 7 + 10 / 3 ≈ 14.33`.
- **Временная переменная при обмене.** После `first_room = second_room` старое значение `first_room` было бы потеряно. Поэтому его заранее сохраняют в `temp_room`, а затем присваивают `second_room`.
- **Форматирование денег.** `f"{value:.2f}"` выводит ровно два знака после точки: `37.5` → `37.50`. Хранимое число при этом не меняется.
