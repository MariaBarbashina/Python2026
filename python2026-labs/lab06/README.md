### transform.py

| Ввод | Ожидаемый результат | Фактический результат |
|---|---|---|
| `-2 0 5 -2` | исходный `[-2, 0, 5, -2]`, новый `[2, 0, 5, 2]` | `[-2, 0, 5, -2]`, `[2, 0, 5, 2]` |
| пустой ввод | `[]`, `[]` | `[]`, `[]` |
| `1 2 3` (нет отрицательных) | `[1, 2, 3]`, `[1, 2, 3]` | `[1, 2, 3]`, `[1, 2, 3]` |

**Исходный список сохранён.** Новый список строится через `append()` в отдельный пустой список `transformed`. Элементы `numbers` не изменяются, поэтому после преобразования программа выводит исходный список без изменений: `[-2, 0, 5, -2]`.

## Ответы на вопросы защиты

- **`append()` и присваивание по индексу.** `items.append(value)` добавляет новый элемент в конец, и длина списка растёт на 1. `items[i] = value` заменяет уже существующий элемент: длина не меняется, а при несуществующем индексе возникает `IndexError`.
- **`sorted()` и `sort()`.** `sorted(items)` возвращает новый отсортированный список, исходный не меняется. Поэтому в варианте выборка остаётся в исходном порядке. `items.sort()` переставляет элементы в самом списке и возвращает `None`, так что запись `x = items.sort()` даст `x = None`.
- **Копия списка.** `copy = items` не создаёт копию: оба имени указывают на один список. Для независимой копии плоского списка нужен `items.copy()`. В `transform.py` результат строится в отдельном новом списке.
