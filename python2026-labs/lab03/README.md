## Ответы на вопросы защиты

- **Выбор `and` / `or`.** Точка внутри прямоугольника, только если выполнены *оба* условия: по `x` и по `y`. Поэтому используется `and`. Число вне диапазона, если *хотя бы одно* условие нарушено: `progress < 0 or progress > 100`. Поэтому используется `or`.
- **Порядок ветвей.** В цепочке `if`/`elif`/`else` выполняется только первая подходящая ветвь. Поэтому сначала отсекается ошибка диапазона, а затем пороги проверяются по возрастанию: `<= 4`, `<= 94`, остальное. Каждая следующая ветвь уже знает, что предыдущие условия ложны, поэтому нижнюю границу (`>= 5`) отдельно проверять не нужно.
- **Равенство значений.** В `minimum.py` используются нестрогие сравнения `<=`, поэтому при равных числах выбирается первое из них, и ответ всегда верный: `5, 5, 5` → `5`. В варианте все интервалы включают концы, поэтому граничные значения `4`, `5`, `94`, `95` используются в сравнениях `<=` и попадают в нужную категорию.
