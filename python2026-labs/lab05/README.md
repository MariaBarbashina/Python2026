**Вариант:** 10 — слова, которые начинаются и заканчиваются одной и той же буквой.

## Состав

| Файл | Задание |
|---|---|
| `normalize.py` | Задание 1. Нормализация пробелов, подсчёт длин и слов |

| `variant.py` | Индивидуальный вариант 10 |

## Как запустить

Из папки `lab05`:

```text
python normalize.py
python palindrome.py
python replace.py
python variant.py
python palindrome_loop.py
```

## Принятые правила

- **Слово** в нормализации — непустая часть, полученная через `split()`. Знаки препинания остаются частью слова.
- **Палиндром:** регистр и обычные пробелы `" "` игнорируются. Остальные символы, включая пунктуацию, сравниваются как есть.
- **Вариант:** с краёв каждого слова удаляются символы `.,!?;:`, слово переводится в нижний регистр, пустые результаты пропускаются. Слово подходит, если `cleaned.endswith(cleaned[0])`. Поэтому слово из одной буквы (`я`) тоже подходит: оно начинается и заканчивается одной буквой.

## Проверки

### normalize.py

| Ввод | Ожидаемый результат | Фактический результат |
|---|---|---|
| `␣␣Один␣␣␣два␣␣` | исходная длина `14`, новая `8`, текст `Один два`, слов `2` | `14`, `8`, `Один два`, `2` |
| пустая строка | длина `0`, слов `0` | `0`, `0`, `''`, `0` |
| `␣␣␣` (только пробелы) | исходная `3`, новая `0`, слов `0` | `3`, `0`, `''`, `0` |
| `Привет,␣␣␣мир!<Tab>Как␣␣дела?` | табуляция тоже пробельный символ: `Привет, мир! Как дела?`, длина `22`, слов `4` | `25` → `22`, `Привет, мир! Как дела?`, `4` |

### palindrome.py и palindrome_loop.py (сравнение двух решений)

Оба решения запущены на одинаковых входах. Результаты совпали.

| Ввод | Ожидаемый ответ | `palindrome.py` (срез) | `palindrome_loop.py` (цикл) |
|---|---|---|---|
| `А роза упала на лапу Азора` | Палиндром | Палиндром | Палиндром |
| `а␣␣␣␣` | Палиндром | Палиндром | Палиндром |
| строка из пробелов | Нет текста | Нет текста | Нет текста |
| пустая строка | Нет текста | Нет текста | Нет текста |
| `Python` | Не палиндром | Не палиндром | Не палиндром |
| `А!` | Не палиндром (`а!` ≠ `!а`) | Не палиндром | Не палиндром |
| `Шалаш` | Палиндром | Палиндром | Палиндром |
| `ab ba` (чётная длина после очистки) | Палиндром | Палиндром | Палиндром |
| `abca` | Не палиндром | Не палиндром | Не палиндром |

Цикл в `palindrome_loop.py` обходит `len(cleaned) // 2` позиций **очищенной** строки и сравнивает символы `cleaned[i]` и `cleaned[len - 1 - i]`.

## Ответы на вопросы защиты

- **Неизменяемость строк.** Методы `lower()`, `strip()`, `replace()` не меняют исходную строку, а возвращают новую. Поэтому результат нужно присвоить переменной: `cleaned = word.strip(".,!?;:").lower()`. Присваивание по индексу вроде `text[0] = "A"` вызывает `TypeError`.
- **Слово и подстрока.** Слово — отдельная часть текста, полученная через `split()`. Подстрока — любой непрерывный фрагмент строки. Например, `"ра"` — подстрока слова `"рама"`, но не отдельное слово. Проверка `"ра" in text` найдёт подстроку и внутри других слов.
- **Почему правила пунктуации задают заранее.** От них зависит ответ. Без очистки слово `Анна,` заканчивается на `,` и не подойдёт под вариант. Для палиндрома `А!` по принятым правилам — не палиндром, а если бы пунктуацию удаляли, был бы палиндромом. Правило нужно выбрать до программы, чтобы проверки имели однозначный ожидаемый результат.
